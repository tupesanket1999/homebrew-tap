# tupesanket1999/tap

Homebrew formulae by [@tupesanket1999](https://github.com/tupesanket1999).

## Jester

A tiny animated jester that floats on your screen and tells you when Claude Code is done or needs your OK.
[Project page](https://github.com/tupesanket1999/jester).

```bash
brew install tupesanket1999/tap/jester
brew services start jester
jester hooks install
```

Builds from source (about a minute; needs the Xcode command-line tools).
